# Project Overview

This project contains two separate web applications:

1.  **Road Trip Family App (`index.html`)**: A detailed travel planner for a family road trip from Mascali to Rome in August 2025. It includes an interactive map, daily itineraries, weather information, budget tracking, and more. It is designed to work offline thanks to a service worker.

2.  **Mortgage Calculator (`mortgage_calculator.html`)**: A form-based application for a mortgage consultancy interview. It calculates monthly net income, loan payments, and generates a summary report.

## How to Use

-   To view the Road Trip App, open `index.html` in a web browser.
-   To view the Mortgage Calculator, open `mortgage_calculator.html` in a web browser.
